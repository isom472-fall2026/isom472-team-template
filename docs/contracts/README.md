# Contracts

One file per boundary, named after the thing that passes across it, not after the people on
either side — `order_line.md`, not `sara_to_ahmad.md`. The card arrives in a pull request,
and the other party's review **is** the agreement: once they have said what they checked and
approved it, the shape is settled and neither side changes it quietly.

Head each contract file like this:

```
## Contract: <the_name_of_what_is_passed>
```
